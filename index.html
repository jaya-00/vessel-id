About the project.

This project explores how computer vision can be used to suggest the cultural classification of an ancient vessel from a photograph.

The current model learns visual patterns from vessel images sourced from The Metropolitan Museum of Art’s open collection data.

The goal is not to replace curatorial expertise or formal attribution. Instead, this experimental MVP explores how image classification might support discovery, education, and engagement with cultural collections.

What can it recognize?

The current model is trained on vessel images sourced from The Metropolitan Museum of Art’s open collection data.

Current MVP categories

Greek Roman Egyptian East Asian Near Eastern

This classifier is an independent, experimental prototype and is not an official tool of The Metropolitan Museum of Art. Predictions are intended for exploration and should not be treated as formal object attributions.
